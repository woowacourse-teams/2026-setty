# 배송 시뮬레이터 (시연 도구)

시연장에서는 폰을 들고 250m 칸을 넘어 다닐 수 없어서, 이 페이지가 실제 도로 경로를 따라 배송원 위치를 대신 움직입니다.
서비스 기능이 아닙니다. 시연 노트북에서 로컬로만 띄우고, client/ 빌드와 서버 배포에 포함하지 않습니다.

- 지도: Leaflet + OpenStreetMap 타일, 250m 격자(서버 칸 계산과 같은 식) 40칸
- 경로: 로컬 OSRM `/route`
- 위치: 1.5초마다 `PUT /api/delivery/location {lat, lng}` (배송원 토큰)
- 폰 연결: 로그인한 토큰을 QR(`<폰 주소>/driver#token=…&sim=1`)로 넘김. 폰에서 따로 로그인하지 않습니다.

## 시연 순서

### 1. OSRM 띄우기
```bash
cd tools/delivery-sim
npm install
./osrm.sh
```
- `~/osrm/seoul.osrm.*`(서울 car, MLD)을 씁니다. 다른 곳에 있으면 `OSRM_DATA_DIR=경로 ./osrm.sh`.
- 이미지는 데이터를 만든 버전(v26.10.0)으로 고정했습니다. 버전이 다르면 엔진이 뜨지 않습니다.
- 끌 때: `docker rm -f delivery-sim-osrm`

### 2. 대상 서버를 정해 띄우기
```bash
SIM_API_URL=https://<prod 서버 주소> SIM_CLIENT_URL=https://<배송원 웹 주소> npm run dev
```
http://localhost:5180 을 엽니다.

| 설정 | 기본값 | 뜻 |
|---|---|---|
| `SIM_API_URL` | `http://localhost:8080` | `/api`를 넘길 서버. 시연 때는 prod |
| `SIM_CLIENT_URL` | `http://<노트북 LAN IP>:3000` | QR에 담을 배송원 웹 주소. 폰에서 열 수 있어야 함. 노트북의 client 개발 서버를 쓸 때는 `npx webpack serve --mode development --no-compress`로 띄워야 SSE가 바로 옵니다 |
| `SIM_OSRM_URL` | `http://localhost:5008` | `/osrm`을 넘길 OSRM |
| `SIM_AREA` | `37.4926,126.9265,8,5` | 격자 영역: 남쪽 위도, 서쪽 경도, 가로 칸 수, 세로 칸 수(상도3·4동 일대) |

프록시가 요청의 Origin 헤더를 떼므로 서버 CORS 설정은 바꾸지 않아도 됩니다.

### 3. 계정 준비
- 배송원 계정: 동시에 체험할 인원 수만큼. 시뮬레이터 하나에 폰 하나가 짝입니다.
- 판매자·구매자: 격자 영역 안 주소로 가입한 회원. 이들의 주문이 확정되면 출발·도착 칸이 정해진 콜이 생깁니다.
- 체험할 배송원이 진행 중 배차를 한 건 이상 갖고 있어야 "가는 길에 실을 콜"이 뜹니다.

### 4. 진행
1. 시뮬레이터에서 배송원 아이디로 로그인합니다.
2. 화면의 QR을 체험자가 폰 기본 카메라로 찍습니다. 같은 토큰으로 로그인된 배송원 웹이 열립니다.
3. 지도에서 출발지를 찍습니다. "진행 중 배차 도착 주소 보기"를 누르면 내 배차의 도착 주소가 나오니, 그 근처를 목적지로 찍습니다.
4. 출발을 누르면 차가 도로를 따라 움직입니다. 속도는 1·2·4·8배(1배 = 시속 30km).
5. 패널에서 현재 위도·경도·칸 번호, 서버가 받은 칸, 묶음 후보 건수를 봅니다. 후보가 1건 이상이면 폰의 "가는 길에 실을 콜"에 뜹니다.

## 주의
- 로그인 토큰은 시뮬레이터 탭에만 둡니다. 탭을 닫으면 다시 로그인하고 QR을 새로 찍습니다.
- 콜을 보여 줄 칸은 경로가 그 칸 가운데를 지나게 고르고 속도는 1~2배를 씁니다. 칸 모서리만 스치면 그 칸에 1초쯤만 머물러 폰에 콜이 거의 안 보입니다.
- 진행자가 다른 곳에서 같은 배송원으로 다시 로그인하면 이전 토큰이 끊깁니다. 위치 전송이 401이면 시뮬레이터에서 다시 로그인하고 QR을 새로 찍습니다.
- 시뮬레이터 창이 가려져도 차는 계속 갑니다. 다만 브라우저가 가려진 탭의 타이머를 1초 간격으로 늦추므로, 지도 움직임을 보여 줄 때는 탭을 앞에 둡니다.
- 원본 좌표·주소 자료는 이 폴더에 넣지 않습니다. 영역은 경계 숫자만 둡니다.
