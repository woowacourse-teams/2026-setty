# PR 제목

PR 제목은 연결된 Issue의 제목과 정확히 같게 작성한다.

## 영역 라벨

- 결과가 `client/**` 또는 클라이언트 관련 작업이면 `client` 라벨을 붙인다.
- 결과가 `server/**` 또는 서버 관련 작업이면 `server` 라벨을 붙인다.
- 결과가 앞선 두 영역과 관련이 없으면 라벨을 붙이지 않는다.

## PR 필수 내용

PR 본문에는 변경의 배경과 결과를 검토자가 이해할 수 있도록 최소한 다음 내용을 포함한다.

- **해결하려는 문제가 무엇인가요?**
- **왜 해야 하나요?**
- **어떻게 해결했나요?**

각 항목에는 해당 PR의 실제 변경 내용만 간결하게 작성한다.

## 대상 브랜치

모든 PR은 `develop` 브랜치를 대상으로 생성한다.
