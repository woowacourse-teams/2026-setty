# 배송 요청 SSE 복구 결과

## 검증 & 결과

- 앱 SSE 단절 중 생성·수락·취소: 격리 통합 테스트 통과. 재연결 후 목록 API에는 수락 가능한 요청만 남고 수락·취소 요청 잔존은 0건이었다. 서버 재시작은 사용자가 기사 기기에서 약 1초 내 복구됐고, API·화면 ID 일치와 로컬 거절 반영을 확인했다. 앱 복귀 검증은 미실시다.
- 서버 재시작 후 복원: 격리 API 기준 P95 **3.074초**(30회, `serverReadyAt`은 인증 목록 API 첫 200). API 부적합 요청 잔존 **0건**, 누락 **0건**, 시간 초과 **0회**였다. 화면 렌더링은 측정하지 않았다. [30회 원시 기록](delivery-request-sse-api-recovery-2026-10-07.jsonl)
