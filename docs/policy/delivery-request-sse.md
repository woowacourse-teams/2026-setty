# 배송 요청 SSE 연결 허용 정책

**채택: 같은 기사에게 동시에 최대 2개의 배송 요청 SSE 연결을 허용한다.** 재접속 중 이전 연결과 새 연결의 일시적 중첩을 허용하기 위한 정책이다. 전체 연결 상한 수치와 초과 연결 처리 방식의 확정은 **보류**한다.

- 결정일: 2026-10-12.
- 대상: 기사 앱의 배송 요청 목록 SSE(Server-Sent Events: 열린 HTTP 연결로 서버 이벤트를 전달하는 방식), `GET /api/delivery/requests/events`.
- 적용 범위: 현재의 단일 서버. 여러 서버 사이의 기사별 연결 수 공유는 **비범위**다.
- 구현 상태: 연결 수 제한 구현과 후속 검증은 미착수다.

## 기사당 최대 2개 허용

- 같은 기사는 인증된 기사 ID로 구분한다. 같은 기기의 재접속과 다른 기기의 접속 모두 같은 기사의 연결 수에 포함한다.
- 서버에 등록되어 종료가 확인되지 않은 연결은 허용 개수에 포함한다. 앱이 연결을 닫았더라도 서버가 아직 종료를 확인하지 못했다면 포함한다.
- 동시 구독 요청에도 기사당 등록된 연결 수는 2개를 넘지 않아야 한다.
- 연결 종료가 확인되면 해당 연결이 차지한 허용 개수를 복구한다. 같은 연결의 종료 처리가 중복되어도 한 번만 복구한다.

두 연결을 항상 열어두는 정책은 아니다. 정상 연결이 1개인 동안에는 다른 연결을 추가로 만들 필요가 없다.

## 재접속 여유와 자원 비용

앱이 기존 연결을 닫고 새 연결을 시작해도 서버의 종료 확인은 늦을 수 있다. 기사당 1개만 허용하면 이 구간에서 재접속이 제한될 수 있다. 최대 2개를 허용하면 기존 연결 1개가 남아 있는 동안 새 연결 1개를 받을 수 있다.

이 선택은 두 기기의 동시 사용도 허용한다. 두 연결이 모두 사용되면 기사당 1개 제한보다 많은 연결 자원을 점유한다. 이미 2개가 등록된 상태에서 추가 재접속이 도착하는 상황까지 해소하지는 않는다. 실제 재접속 지연 완화 효과와 메모리 증가량은 **확인 필요**다.

## 유지할 동작

- 연결 타임아웃 120초와 heartbeat 간격 15초는 **유지**한다. 타임아웃은 연결 수명을 제한하며 동시 연결 개수의 상한을 대신하지 않는다.
- 커밋 후 목록 변경 신호 전달과 재접속 후 기존 목록 API를 통한 최신 상태 복구는 **유지**한다.
- 비동기 전송 구조 변경은 **보류**한다. 이번 정책의 범위는 연결 허용 개수다.

## 보류한 설정과 처리 방식

아래 검토 후보는 현재 확정된 규칙이 아니다. 구현 전에 별도로 결정한다.

| 항목 | 상태 | 검토 후보와 확인할 내용 |
| --- | --- | --- |
| 인스턴스당 전체 연결 상한 수치 | 보류 | 개발·검증 초기값으로 100개를 제안했다. 운영 상한은 예상 동시 연결 수, 서버 heap·프로세스 메모리 측정, 프록시 설정으로 정한다. 100개를 검증된 운영 용량으로 사용하지 않는다. |
| 초과 연결 처리 방식 | 보류 | 기존 연결을 유지하고 신규 연결을 거부하는 방식을 권장했다. 이전 연결 정리가 늦으면 신규 접속이 지연될 수 있으므로 복구 동작을 확인한다. |
| 초과 응답과 재시도 안내 | 보류 | 기사별 초과에 HTTP 429, 전체 상한 초과에 HTTP 503, 초기 `Retry-After` 5초를 제안했다. 초과 처리 방식과 함께 확정한다. |
| 앱의 재시도 조정 | 보류 | 서버의 재시도 안내 반영과 재시도 시점을 분산하는 무작위 지연을 검토한다. |

## 후속 검증 기준

1. 같은 기사에게 2개까지 등록할 수 있고, 동시 요청에서도 등록 수가 2개를 넘지 않는다.
2. 다른 기사의 등록 수는 해당 기사의 상한을 판정할 때 포함하지 않는다. 전체 상한은 별도로 판정한다.
3. 완료·타임아웃·오류·전송 실패로 연결을 정리하면 허용 개수가 정확히 복구된다. 중복 정리로 개수가 잘못 감소하지 않는다.
4. 실제 HTTP 연결에서 기존 연결의 종료 확인이 늦는 구간에 새 연결을 허용하고, 정리 후 다시 등록할 수 있다.
5. 재접속 후 목록이 최신 상태와 일치한다. 연결 개수 제한 검증과 실제 메모리·복구 시간 측정 결과는 구분한다.
