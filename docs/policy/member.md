# 회원 정책

회원 계정의 탈퇴 조건과 탈퇴 뒤 데이터 처리를 정의한다. 배송원 계정은 다루지 않는다.

## 탈퇴 조건

- 구매자나 판매자로서 진행 중인 거래가 있으면 탈퇴할 수 없다. 진행 중인 거래는 주문 상태가 `PENDING`·`CONFIRMED`·`CANCEL_PENDING`인 주문이다.
- 배송이 끝나 자동 완료를 기다리는 `CONFIRMED` 주문도 진행 중으로 본다. 구매 확정 전이라 취소·환불이 열려 있기 때문이다.
- 주문이 `COMPLETED`·`CANCELLED`·`EXPIRED`만 남아 있으면 탈퇴할 수 있다.
- 탈퇴는 확인 다이얼로그 한 번으로 진행하고 비밀번호를 다시 받지 않는다.

## 탈퇴 처리

- **판매 중 매물:** 구매 신청이 없는 판매 중 매물은 함께 내린다(soft delete). 사진은 저장소에서 지운다. 판매 완료 매물은 거래 기록이라 남긴다.
- **개인 설정:** 찜, 키워드 구독, 기기 토큰, 받은 알림은 지운다. 거래 기록이 아니고, 남기면 탈퇴 회원에게 알림을 계속 만든다.
- **거래 기록:** 주문·결제·정산 행은 그대로 둔다. 다른 회원의 거래 기록이 이 회원을 가리키기 때문이다.
- **회원 행:** 지우지 않고 개인정보 칸만 가린다.

| 칸 | 탈퇴 뒤 |
| --- | --- |
| 아이디 | `withdrawn-{회원 id}` |
| 비밀번호 | 아무도 모르는 값의 해시 |
| 전화번호 | `000-0000-0000` |
| 주소 | `탈퇴한 회원` |
| 행정동·표준 주소 | 비움(주소 해석 상태는 `UNMATCHED`) |
| 로그인 토큰 | 비움 |
| 탈퇴 시각 | 기록 |

## 탈퇴 뒤 계정

- 원래 아이디로 로그인할 수 없다.
- 같은 아이디로 다시 가입할 수 있다. 새 계정은 이전 계정의 거래 기록과 이어지지 않는다.
- 탈퇴는 되돌릴 수 없다.
