# SETTY 정책 문서

이 디렉터리는 확정된 도메인·서비스 흐름 정책의 원본이다. 각 규칙은 담당 문서 한 곳에서 정의한다. 구현 방법은 패키지 내부 문서와 코드에서 관리한다. 각 문서의 **확인 필요·잠정 채택·보류·후순위** 항목은 현재 유효한 정책이 아니다.

## 정책 목록

- [주문·매물](order.md): 주문 상태, 6분 만료, 매물 점유, 취소 조건
- [결제](payment.md): 결제 금액, 승인·실패·결과 미확정, 환불
- [배송](delivery.md): 배송 요청, 정보 확정, 배차와 배송 상태
- [판매 완료·정산](completion-settlement.md): 구매자 확인, 자동 완료, 판매자·기사 정산
- [고객 상태·알림](customer-status.md): 상태 노출과 배송 알림
- [정책 문서 운영 가이드](policy-guide.md): 정책 변경 절차
